x402 ブラウザ検証 待機

課金プロキシのフローをブラウザで確認します。ステップ1で 402 を取得し、Injected Wallet（MetaMask 等）で支払いヘッダーを作成するか、 X-PAYMENT を手入力してから再リクエストします。認証 Cookie は HttpOnly のため JavaScript からは読めません。ステップ4が成功すれば Cookie が有効です。

接続設定

テストネットではウォレットに Base Sepolia の ETH（ガス）とテスト USDC が必要です。

手動モード（任意）

手入力する場合は「Injected Wallet で署名」をスキップし、ステップ3から実行できます。
